PINN design: architecture and inductive biases
Module 4 • two networks share one physics loss • six design choices enforce SEIRD structure exactly

The observability problem

  • Surveillance reports only two series: cumulative cases C and deaths D
  • Hidden compartments S, E, I are never measured
  • Transmission β(t) and mortality μ must be inferred from C and D alone

Observable re-parameterisation

Set C = I + R + D (all symptomatic). Then S = N − E − C exactly, so total population conservation S+E+I+R+D = N holds identically for any network output.

Dual-network architecture

  • State net gθ(τ): 3×48 tanh units, 4 positive outputs:
    e = e0 eτ g1,   i = i0 eτ g2,   c = c0 eτ g3,   d = d0 + τ g4
  • Transmission net hφ(τ): 3×32 tanh units:
    β(τ) = Softplus(hφ(τ) + b) > 0

Six inductive biases

  1. Hard ICs: Exponential factor e0eτ g1 guarantees e(0)=e0 exactly; τ factor enforces zero IC gradient at τ=0.
  2. Positivity: Softplus and exp mappings strictly prevent negative populations.
  3. CFR bounds: μ = γ CFR / (1−CFR) with CFR ∈ (0.2, 0.8), eliminating the degenerate μ → 0 attractor.
  4. Fourier features: Inputs [sin(kπτ), cos(kπτ)] for k=1..4 defeat neural spectral bias so rapid β(t) shifts are captured.
  5. Relative ODE residuals: Each residual scaled by state magnitude so early small-scale dynamics are weighted equally with the peak.
  6. Smooth prior on β: Penalty on (dβ/dτ)2 renders the ill-posed inverse problem well-conditioned.
What the architecture guarantees without training: Total population conservation S+E+I+R+D = N to machine precision (2×10−16); positive states; exact initial conditions; biological CFR range [20%, 80%].
