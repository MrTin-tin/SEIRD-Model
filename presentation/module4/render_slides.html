PINN design: architecture and inductive biases

The observability problem

  • Surveillance reports only two series: cumulative cases C and deaths D
  • Hidden compartments S, E, I are never measured
  • Transmission β(t) and mortality μ must be inferred from C and D alone

Observable re-parameterisation

Set C = I + R + D (all symptomatic). Then S = N − E − C exactly, so total population conservation S+E+I+R+D = N holds identically for any network output.

Dual-network architecture

  • State net gθ(τ): 3×48 tanh units, 4 positive outputs:
    e = e0 eτ g1,   i = i0 eτ g2,   c = c0 eτ g3,   d = d0 + τ g4
  • Transmission net hφ(τ): 3×32 tanh units:
    β(τ) = Softplus(hφ(τ) + b) > 0

Six inductive biases

  1. Hard ICs: Exponential factor e0eτ g1 guarantees e(0)=e0 exactly; τ factor enforces zero IC gradient at τ=0.
  2. Positivity: Softplus and exp mappings strictly prevent negative populations.
  3. CFR bounds: μ = γ CFR / (1−CFR) with CFR ∈ (0.2, 0.8), eliminating the degenerate μ → 0 attractor.
  4. Fourier features: Inputs [sin(kπτ), cos(kπτ)] for k=1..4 defeat neural spectral bias so rapid β(t) shifts are captured.
  5. Relative ODE residuals: Each residual scaled by state magnitude so early small-scale dynamics are weighted equally with the peak.
  6. Smooth prior on β: Penalty on (dβ/dτ)2 renders the ill-posed inverse problem well-conditioned.
What the architecture guarantees without training: Total population conservation S+E+I+R+D = N to machine precision (2×10−16); positive states; exact initial conditions; biological CFR range [20%, 80%].

Loss function and training protocol

Total loss formulation

L = (LC + LD) + Lode + wsm Lsmooth
  • LC, LD: Mean squared error evaluated exclusively at real report dates (no interpolation artifacts).
  • Lode: Autograd relative ODE residuals over Nf = 200 collocation points:
    Σ [(e' − Tfe)/e]2 + [(i' − Tfi)/i]2 + [(c' − Tfc)/c]2 + [(d' − Tfd)/d]2
  • Lsmooth: Mean squared derivative Σ (dβ/dτ)2.

Why relative ODE residuals?

An outbreak grows exponentially across orders of magnitude. Under standard absolute residuals, early-stage errors contribute negligible loss. The E6 ablation reveals absolute residuals yield 75%–128% error vs. < 0.2% under relative scaling.

Two-stage optimiser

  • Stage 1 — Adam: LR 2×10−3 with cosine annealing, 2000 iterations. Resamples random collocation points per step to escape local minima.
  • Stage 2 — L-BFGS: Strong-Wolfe line search (2500–6000 iters) on a fixed linspace grid for quadratic convergence.
  • Float64 precision: Strict double precision prevents rounding errors during higher-order autograd differentiation.
  • Ensemble: 5 random seeds; median trajectory acts as robust point forecast.

Forecasting protocol

Hold β at its empirical 14-day trailing mean; freeze inferred μ; propagate SEIRD forward via DOP853 numerical solver.

Ablation insights (E6)

Adam-only: e(t) error jumps to 96%. Physics weight wode = 10: errors triple. Fourier features reduce β RMSE by 28%.

Key design decision: The L-BFGS second-order refinement is indispensable. Adam alone establishes coarse trends, but fails to resolve stiff ODE phase trajectories.
