1. Introduction and Motivation

Surveillance systems for Ebola report two cumulative quantities at irregular dates: confirmed cases C(t) and confirmed deaths D(t). Every other epidemiologically relevant quantity—the susceptible fraction S, the incubating population E, the currently infectious I, and most critically the time-varying transmission rate β(t)—is latent. Classical approaches handle this latency by assuming a parametric shape for β(t) in advance (a step function, an exponential decay, or piecewise-constant segments). Each assumption has a qualitative cost: a step can never anticipate a second wave; an exponential can only decrease monotonically.

Physics-informed neural networks (PINNs) offer a fundamentally different strategy. Two small neural networks jointly represent the state trajectories and β(t) continuously, and are trained to minimise a composite loss function combining fidelity to empirical observations with a residual of the SEIRD ordinary differential equations evaluated via automatic differentiation. No predetermined functional form for β(t) is imposed. The ODE constraint propagates observational signals from cases and deaths into the unmeasured compartments: by enforcing consistency with epidemiological dynamics, the network is compelled to reconstruct latent states E and I faithfully.

2. Architecture and Inductive Biases

2.1 Observable Re-parameterisation

Let C(t) = I(t) + R(t) + D(t) denote the cumulative symptomatic incidence. Differentiating yields dC/dt = σ E. The standard SEIRD equations can therefore be rewritten using (E, I, C, D):

dE/dt = β(t)(S/N)I − σE,   dI/dt = σE − (γ + μ)I,   dC/dt = σE,   dD/dt = μI

with algebraic recoveries R = C − I − D and S = N − E − C. Consequently, the mass conservation identity S + E + I + R + D = N holds identically across all candidate network outputs, converting a difficult manifold constraint into an architectural invariant.

2.2 Dual-Network Architecture

The framework deploys two decoupled feed-forward networks:

  • State network gθ(τ): 3 hidden layers of 48 tanh units with 4 outputs parameterising normalised time τ ∈ [0, 1]:
    e = e0 eτ g1,   i = i0 eτ g2,   c = c0 eτ g3,   d = d0 + τ g4
  • Transmission network hφ(τ): 3 hidden layers of 32 tanh units with β(τ) = Softplus(hφ(τ) + b) > 0.

2.3 Inductive Biases

Six foundational inductive biases ensure physical validity prior to parameter optimisation: (1) Hard initial conditions via exponential factors ensure zero gradient error at τ=0; (2) Strict positivity eliminates biologically impossible negative populations; (3) CFR parameterisation μ = γ CFR / (1 − CFR) with CFR ∈ (0.2, 0.8) blocks the degenerate μ → 0 branch; (4) Fourier feature embeddings resolve spectral bias; (5) Relative ODE residuals prevent early-stage dynamic attenuation; (6) Smoothness regularisation stabilises derivative ill-conditioning.
